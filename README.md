# Кластеризация экономической структуры российских муниципалитетов

Проект посвящён выявлению скрытой экономической структуры российских муниципалитетов с использованием кластеризации на атрибутированных динамических сетях. Основная идея проекта это представить каждый муниципалитет как узел экономической сети, а экономические показатели используются как его атрибуты и связи между муниципалитетами отражают степень их экономической близости.


В рамках проекта решаются следующие задачи:
- Подготовка и очистка исходных данных.
- Формирование набора экономических признаков муниципалитетов.
- Построение пространства экономических признаков.
- Определение меры экономической близости между муниципалитетами.
- Построение атрибутированной экономической сети.
- Кластеризация муниципалитетов.
- Анализ изменения кластеров во времени.
- Оценка качества полученных кластеров.
- Экономическая интерпретация выделенных групп.
- Визуализация результатов.

Для работы проекта требуется Python версии 3.10 или выше.

Установить зависимости:
pip install -r requirements.txt

Структура проекта:

Data.json             # сам json файл

FromParquetToJson.py  # файл для создания json файла

requirements.txt      # зависимости

README.md             # описание проекта

Результаты

В результате работы алгоритма для каждого периода формируется кластеризация муниципалитетов.

Итоговый анализ позволяет ответить на следующие вопросы:
Какие муниципалитеты имеют похожую экономическую структуру?
Какие типы локальных экономик существуют?
Какие муниципалитеты наиболее устойчиво относятся к определённому кластеру?
Какие муниципалитеты меняют свой экономический тип?
Как меняется экономическая структура муниципалитетов во времени?
Какие кластеры являются наиболее устойчивыми?

Проект выполняется на основе данных конкурса СберИндекс в категории "Кластеризация"
